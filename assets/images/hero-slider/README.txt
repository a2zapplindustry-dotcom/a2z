Put your hero slider images in this folder.

- Any common image format works: .jpg, .jpeg, .png, .webp, .gif, .avif, .bmp, .svg
- Images are shown in file-name order (e.g. 1.jpg, 2.jpg, 3.jpg or slide-1.png, slide-2.png...)
  so name them with numbers if you want a specific order.
- Recommended size: at least 1000 x 560 px (roughly 16:9), landscape orientation works best
  since the box is rectangular and images are cropped to fill it (object-fit: cover).
- The slider auto-plays every 3.5 seconds and also has left/right arrows + dots for manual control.
- If this folder is empty, a placeholder box is shown instead — nothing breaks.

You can delete this README.txt file itself; it will not be picked up as a slide
(only image file extensions are read).
